# 👻 GhostMatrixX Bot

بوت تيليجرام احترافي لبيع الأرقام المؤقتة، مع دعم الدفع عبر المحافظ المصرية.

## ✨ الميزات

- 📱 أرقام مؤقتة لمنصات متعددة
- 🌍 دعم دول متعددة
- 💳 دفع عبر فودافون كاش / أورنج موني / اتصالات كاش / WE Pay
- 🎁 نظام أرقام مجانية (للمالك والمستخدمين المميزين)
- 👑 لوحة تحكم كاملة للمالك
- 📊 إحصائيات مباشرة

## 🚀 التثبيت

```bash
git clone https://github.com/magedatef2/GhostMatrixX_bot.git
cd GhostMatrixX_bot
python -m venv venv
source venv/bin/activate   # Linux/Mac
venv\Scripts\activate      # Windows
pip install -r requirements.txt
cp .env.example .env
# عدّل .env وأدخل القيم الحقيقية
python main.py
