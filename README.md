# GhostNum

Telegram administration and demo number-management bot.

## Features

- Owner-only access
- Country management
- Enable/disable countries
- Add countries
- Number inventory
- Add numbers
- Delete numbers
- Rotate used numbers
- Orders management
- Close orders
- Return numbers to inventory
- Messages
- Users
- Statistics
- Advanced statistics
- Settings
- Maintenance mode setting
- Demo OTP setting
- Broadcast
- Audit log
- SQLite database
- Environment variables
- GitHub-safe secret handling
